ChimeraDB unsigned APT test

Temporary test repository. Use only on disposable Debian test machines.

This feed contains unsigned repository metadata. The trust override below applies only to this test source. The production signed repository is pending setup.

Packages: 0.1.0-3, amd64 only. Debian 12 (bookworm) uses MariaDB 10.11; Debian 13 (trixie) uses MariaDB 11.8.

Test installation

Run as root on a disposable Debian 12 or 13 amd64 machine:

apt-get update
apt-get install -y ca-certificates
. /etc/os-release
case "$ID:$VERSION_CODENAME:$(dpkg --print-architecture)" in
  debian:bookworm:amd64|debian:trixie:amd64) ;;
  *) echo 'Unsupported test host'; exit 1 ;;
esac
cat > /etc/apt/sources.list.d/chimeradb-test.sources <<EOF
Types: deb
URIs: https://mieweb.github.io/chimeraDB/apt-test
Suites: $VERSION_CODENAME
Components: main
Architectures: amd64
Trusted: yes
EOF
apt-get update --error-on=any
apt-get install chimeradb
systemctl restart mariadb
chimeradb setup
chimeradb status

Removing /etc/apt/sources.list.d/chimeradb-test.sources and running apt-get update removes the test feed. Installed packages and database data remain.
